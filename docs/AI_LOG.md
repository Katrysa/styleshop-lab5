# Журнал взаємодії зі ШІ (лабораторна робота № 5)

ШІ-інструмент: Claude (Claude Code), модель Claude Sonnet 5.5.

## Початковий промпт
Створи вебзастосунок інтернет-магазину STYLESHOP на основі клієнтської частини з лабораторних робіт № 1–4. Архітектура: клієнт (HTML/CSS/JS) — сервер Node.js — база даних SQLite. REST API у форматі JSON для товарів, замовлень, підписників і повідомлень; CRUD для товарів і замовлень; адмін-операції захищені токеном зі змінної середовища. Сервер сам рахує суму замовлення за цінами з БД. Вимоги: валідація на сервері, безпечні заголовки, ліміт запитів, без зберігання секретів у коді, автотести, доступність (WCAG AA) і швидкодія.

## Ітерації та виправлення
| № | Що згенерував ШІ | Що виявлено | Що змінено |
|---|---|---|---|
| 1 | Структура папок командою mkdir з {} | Створилась папка «{server» | Видалено, створено командою bash |
| 2 | Скрипт тестів `node --test test/` | Помилка MODULE_NOT_FOUND | Змінено на `node --test` |
| 3 | Тест статичних файлів | Тест падав (порт, 304, сторінка 404) | Тест переписано |
| 4 | Форма товару в адмінці | Вбудована валідація браузера блокувала власні повідомлення | Додано novalidate |
| 5 | Очікування в e2e через рядок JS | Заблоковано політикою CSP | Очікування за селекторами |
| 6 | Адмін-сторінка на 320 px | Горизонтальна прокрутка | Менший мінімум розміру h1 і перенесення слів |
| 7 | Вимірювання швидкодії | Відповідь 429 (ліміт запитів) | Додано змінну RATE_MAX |
| 8 | Колір допоміжного тексту #6F655B | Контраст 4,36:1 на світло-бежевому фоні (< 4,5) | Колір #675D54 (≥ 4,9:1) |
